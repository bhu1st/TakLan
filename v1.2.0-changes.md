# Walkthrough - Minimize to System Tray & Run at Startup

We have implemented system tray support, minimize-to-tray on minimize button click, and a "Run at Startup" context menu toggle option for the LAN Msngr desktop application.

## Changes Made

### Go Backend & Native Windows Integration

#### [`tray_windows.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/pkg/systray/tray_windows.go)
- Implemented pure-Go Win32 system tray icon management using standard Windows APIs (`shell32.dll`, `user32.dll`).
- Handled tray icon creation, double-click/left-click window restoration, and right-click context menu.
- Context menu options:
  - **Open LAN Msngr**: Restores and focuses the application window (`wailsRuntime.WindowShow` & `wailsRuntime.WindowUnminimise`).
  - **Run at Startup**: Interacts directly with Windows Registry (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) to toggle automatic Windows startup with native checkmark indicators (`MF_CHECKED` / `MF_UNCHECKED`).
  - **Exit**: Quits the application (`wailsRuntime.Quit`).

#### [`tray_other.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/pkg/systray/tray_other.go)
- Added no-op fallback implementation for cross-compilation on non-Windows platforms.

#### [`app.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/app.go)
- Integrated `systray.Start("LAN Msngr", ...)` on startup and clean `systray.Stop()` on shutdown.
- Added `MinimizeToTray()` backend method.

### React Frontend

#### [`App.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/App.tsx)
- Added window state listener that automatically detects window minimization (`WindowIsMinimised()`) and calls `WindowHide()`, cleanly moving the window into the System Tray when clicking the native minimize button.

#### [`App.js`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/wailsjs/go/main/App.js) & [`App.d.ts`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/wailsjs/go/main/App.d.ts)

### SQLite Message & File Transfer Persistence (Desktop & Android)
1. **SQLite Database Storage ([`db.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/pkg/db/db.go))**:
   - Integrated `modernc.org/sqlite` (pure Go, 100% CGO-free) database saved directly in the application executable directory (`history.db`).
   - Automatically stores known peers (`peers` table), chat messages (`messages` table), and file transfers with saved file paths (`file_transfers` table).
2. **Local Path Isolation & App Launcher ([`app.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/app.go), [`FileCard.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/components/FileCard.tsx) & [`FileCard.tsx`](file:///z:/xampp82/htdocs/lanmsngr/mobile/src/components/FileCard.tsx))**:
   - Added `offer.status` fallback in both Desktop and Android `FileCard` components (`progress?.status || (offer as any).status || 'offered'`).
   - Ensures completed file transfers (whether active in memory or loaded from SQLite history) permanently render **✓ Transfer Completed** and the **"Open File"** launcher button on both Desktop and Android.
   - Tapping **"Open File"** or the card launches the file directly in default system applications.
3. **Cursor Pagination & Scroll-Up Load More ([`db.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/pkg/db/db.go), [`App.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/App.tsx) & [`ChatArea.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/components/ChatArea.tsx))**:
   - Implemented high-performance cursor pagination querying the **latest 100 items** on initial load.
   - Scrolling up near the top of the chat area (or clicking **"Load Older Messages"**) queries the preceding batch of 100 items via timestamp cursor and prepends them seamlessly while preserving scroll position.
3. **Comprehensive Sent & Received History Browsing ([`db.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/pkg/db/db.go) & [`App.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/App.tsx))**:
   - Enhanced SQLite queries in `GetMessages` and `GetFileOffers` to match conversations across both session IDs and persistent hostnames.
   - When browsing online or offline peers, the app loads **both sent and received chat messages and file transfers** chronologically sorted by timestamp.
4. **File Transfer Path Storage & Default App Launcher ([`app.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/app.go) & [`FileCard.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/components/FileCard.tsx))**:
   - Fixed file card rendering and action button display for both incoming and outgoing transfers by matching both session `ID` and persistent network `Hostname`.
   - On completed transfers, displays an **"Open File"** button that launches the file directly in the OS default viewer/application (photos, videos, PDFs, text files, archives).
5. **Cross-Platform Message Routing & Hostname Resolution ([`server.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/pkg/network/server.go) & [`ChatArea.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/components/ChatArea.tsx))**:
   - `server.go` `sendToPeerID` now matches destination clients by both connection `ID` AND persistent `Hostname`.
   - Updated `ChatArea.tsx` timeline filtering to match messages using `senderHostname` / `targetHostname` without requiring an active online `targetPeer` object, ensuring instant delivery and rendering of Android DMs on Desktop.
6. **Persistent Identity & Android Device Resolution ([`network.ts`](file:///z:/xampp82/htdocs/lanmsngr/mobile/src/services/network.ts) & [`app.go`](file:///z:/xampp82/htdocs/lanmsngr/desktop/app.go))**:
   - Fixed Android hostname changes caused by DHCP IP assignments by generating and storing a persistent UUID (`device_id.txt` in app document directory) combined with `Device.modelName`.
   - Android's persistent network `hostname` (e.g. `Pixel6a-8f3a9b2c`) remains 100% identical regardless of DHCP IP reassignments or network switches.
   - Added automatic `resolvePeerHostname(peerID)` in Desktop backend so incoming messages from Android peers automatically resolve and populate `senderHostname` and `targetHostname`.
7. **Online / Offline Peer Indicators ([`Sidebar.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/components/Sidebar.tsx))**:
   - Active LAN devices display a green **Online** status dot.
   - Disconnected devices previously seen on LAN display a gray **Offline** status dot & badge.
8. **Offline Chat & History ([`ChatArea.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/components/ChatArea.tsx) & [`App.tsx`](file:///z:/xampp82/htdocs/lanmsngr/desktop/frontend/src/App.tsx))**:
   - Selecting any offline peer loads their full historical chat messages from SQLite DB.
   - Message input, file attachments, and ping alerts are disabled when viewing an offline peer with a clear notice banner.
